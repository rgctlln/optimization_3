# Лабораторная работа №3: Метод стохастического градиентного спуска (SGD) и его модификации

## Цель
Изучить и исследовать эффективность метода стохастического градиентного спуска (SGD) и его модификаций на задаче линейной или полиномиальной регрессии.

## Задание

### Основное задание

1. Реализовать и исследовать эффективность SGD для решения задачи регрессии:
   - с разным размером батча (от 1 до размера всего датасета);
   - с разной функцией изменения шага (learning rate scheduling);
   - с различной регуляризацией (L1, L2, ElasticNet).

2. Использовать и сравнить библиотечные реализации оптимизаторов:
   - `keras.optimizers`, `torch.optim`:
     - SGD
     - Momentum
     - Nesterov
     - AdaGrad
     - RMSProp
     - Adam
   - Изучить параметры этих методов.

### Исследование

1. Выбрать и использовать датасет (можно сгенерировать или взять из UCI).
2. Сравнить эффективность SGD:
   - по точности;
   - по времени обучения;
   - по потреблению ресурсов (оперативная память, количество арифметических операций).
3. Сравнить различные модификации и гиперпараметры.
4. Разрешено использовать гиперпараметрическую оптимизацию (`optuna` и т.п.).

### Дополнительное задание 1 (по желанию)

- Реализовать или модифицировать сторонний метод на основе SGD.
- Внедрить его в проект и провести сравнение с другими методами.

### Дополнительное задание 2 (по желанию)

- Разобрать и описать постановку задачи оптимизации для другого метода машинного обучения (например, SVM, бустинг).
- Привести пример задачи и её решение.

## Отчёт

Отчёт должен содержать:

- Постановку задачи;
- Описание реализованных и использованных методов;
- Ссылки на реализацию;
- Характеристики экспериментов (объект, стратегия шага, гиперпараметры, критерий остановки);
- Результаты: значения ошибки, количество итераций, вычислений функции и градиента;
- Таблицы и графики;
- Анализ преимуществ и ограничений методов.

2. Полнота и компактность отчёта;
3. Теоретическое понимание методов;
4. Доп. задание 1 (если выполнено);
5. Доп. задание 2 (если выполнено).
